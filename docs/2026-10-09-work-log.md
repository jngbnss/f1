## 1. 가드레일과 맵 이탈

- **문제:** 벽 판정이 1 m 높이라 차가 넘어갔습니다. 기울어진 차의 서스펜션이 벽면을 바닥처럼 밟고 타고 올라가기도 했습니다.
- **수정:**
  - 3단 레일과 3.4 m 철망 펜스를 세우고, 벽 판정도 그 높이까지 올렸습니다.
  - 서스펜션이 벽과 다른 차를 땅으로 인식하지 않게 했습니다.
  - 벽 밖으로 나가면 0.5초 뒤 트랙으로 자동 복귀합니다.
- **검증:** `npm run barrier:test`로 16개 서킷에서 시속 300 km 충돌을 1,152번 해서 이탈 0번입니다.

## 2. F1 차량

- **차체:** Sketchfab "F1 2026 concept (polygon model)"(Qvist_designs, CC-BY-4.0)을 씁니다.
  - `npm run model:f1`이 원본(약 100만 삼각형)을 6만/7천 삼각형으로 줄입니다.
  - 바퀴, 앞날개, 뒷날개를 분리하고, 칠할 부위를 나눕니다.
- **차종:** F1 10개 팀만 남겼습니다. 레이스는 팀메이트 + 나머지 팀 각 2대로 20대입니다.
- **도색:** 팀별 2026 스타일 도색(투톤, 그라데이션, 사이드포드, 밴드), 차 번호(옆면과 노즈), 팀 색 헬멧을 넣었습니다. 로고는 넣지 않았습니다.
- **타이어:** 2026 규격 폭(앞 280 mm, 뒤 375 mm)으로 맞추고, 옆면에 컴파운드 색 띠(소프트 빨강, 미디엄 노랑, 하드 흰색)를 넣었습니다.

## 3. 배경

- **전체 16개 서킷:**
  - Copernicus 위성 고도(주변 산·계곡)와 Sentinel-2 위성사진(2016년판, CC BY 4.0)으로 실제 땅 색을 칠합니다(`scripts/fetch-terrain.ts`).
  - 트랙 자체는 평지 그대로이고, 트랙 밖 130 m부터 실제 높이로 바뀝니다.
- **몬자 집중 작업:**
  - 메뉴에는 몬자만 남겼습니다. 다른 서킷은 `?track=spa`처럼 주소로만 열립니다.
  - 화면 후처리: 접촉 그림자(AO), 빛 번짐, 필름 톤, SMAA를 넣었습니다(pmndrs/postprocessing + N8AO, `?fx=0`으로 끔).
  - 실제 숲: EZ-Tree(MIT)로 만든 사실적인 나무를 8방향에서 찍은 판으로 OSM 숲 영역에 심었습니다. 몬자에 약 3.9만 그루를 심고도 144 fps입니다.
  - 관중석: 기둥, 지붕 앞판, 좌석 줄 음영, 막힌 옆면을 넣었습니다.

## 4. 레이스 기능

- **시점:** C 키로 체이스 → 먼 체이스 → T-캠 → 콕핏 → 노즈캠을 돌아가며 고릅니다. 마지막 시점을 기억하고, `?cam=cockpit`처럼 주소로 정할 수도 있습니다.
- **타이어:**
  - 컴파운드별 접지력, 마모, 작동 온도 범위가 다릅니다.
  - 마모 70%를 넘으면 접지력이 급격히 떨어집니다.
  - 마모 속도는 F1 게임처럼 실제의 4배입니다. 몬자 1랩에 소프트 약 21%, 미디엄 14%, 하드 9%입니다(`npm run tyre:test`).
- **피트 스톱:**
  - 몬자 메인 직선에 피트 레인을 만들었습니다(진입·출구, 80 km/h 제한선, 팀 색 박스, 피트 월).
  - P 키로 피트를 요청하고, 1/2/3으로 다음 타이어를 고릅니다. 이후 진입부터 정차, 교체(약 2.5초), 출구까지 자동입니다.
  - AI는 타이어가 다 닳거나 날개가 부서지면 들어옵니다(`npm run pit:test`).
- **충돌 손상:**
  - 강한 정면 충돌이면 앞날개, 뒤에서 받히면 뒷날개가 손상됩니다.
  - 손상된 날개는 처지고, 60%를 넘으면 떨어져 나가 굴러갑니다. 해당 축의 다운포스가 줄어 차가 덜 돌거나(언더스티어) 뒤가 미끄러집니다(오버스티어).
  - 피트에서 날개를 교체합니다(약 6초 추가). 일반 휠 접촉은 손상이 없습니다(`npm run damage:test`).
- **화면 정보:**
  - 순위표: 20대 전체를 팀 색과 번호(FER 16 등), 선두와의 간격, 타이어, 피트 중 표시로 보여줍니다.
  - 오른쪽 아래 패널: 타이어 마모·온도(차가움/적정/과열), 앞차·뒤차 간격, 날개 손상, 피트 상태를 보여줍니다.
- **레이싱 라인:**
  - 기존의 "곡률 최소" 라인을 "랩타임 최소" 라인으로 다듬었습니다(`npm run raceline:bake`).
  - 몬자 이론 랩타임은 90.84초에서 89.47초로, AI 실제 주행은 95.25초에서 93.98초로 줄었습니다.
- **AI:**
  - 출발 때 그리드 줄을 유지하다 첫 코너 전에 라인에 합류합니다.
  - 속도에 맞춰 앞차와 간격을 두고, 옆 차와 거리를 유지하며, 아스팔트 밖으로 추월 경로를 잡지 않습니다.
  - 닳은 타이어나 부서진 날개에 맞춰 감속합니다.

## 테스트 (모두 통과)

`npm run sim:test -- quick`, `race:test`, `barrier:test`, `pit:test`, `damage:test`, `tyre:test`, 타입 검사, 빌드를 통과했습니다. 게임 화면은 매 단계 스크린샷으로 확인했고, 몬자에서 144 fps를 유지합니다.

## 남은 과제와 알려진 한계

- **AI끼리 사고가 아직 잦습니다.** 몬자 20대 1랩에서 날개가 떨어지는 차가 2~4대, 스파·실버스톤은 7~9대입니다. 원인은 코너에서 서로 밀어내는 접촉입니다. 다음 단계로 AI 간 추월·방어 로직 개선을 제안합니다.
- **트랙 자체는 평지입니다.** 스파 오 루즈 같은 고저차는 없습니다.
- **피트 레인은 몬자만 있습니다.** 다른 서킷은 피트 위치 데이터가 필요합니다.
- **도색은 코드로 그린 단순한 무늬입니다.** 실제 팀 무늬를 정밀하게 재현하려면 UV 텍스처 작업이 필요합니다.
- **2026 규정 특유의 요소는 없습니다.** 배터리 배분, 액티브 에어로(직선 모드), 오버테이크 모드가 해당합니다.
- **팀별 성능 차이가 없습니다.** FastF1 실제 데이터로 맞추는 작업이 남아 있습니다.
- **출처 표기:** 화면 오른쪽 위, README, `public/models/CREDITS.md`에 넣었습니다.

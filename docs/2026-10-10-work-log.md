## 알려진 문제와 확인 못 한 것

- **PC 메모리 문제**: 새벽 2시쯤부터 커널 메모리(비페이징 풀)가 약 14.6 GB까지 차서 화면 없는 크롬 스크린샷이 흰 화면만 나왔습니다. 드라이버 누수로 보이며, 재부팅이 필요합니다. 그래서 모나코의 마지막 수정분(요트 배치, 밝은 바닥, 한쪽 면 표지판)은 화면으로 확인하지 못했습니다.
- **fps 재측정 필요**: 여러 작업이 그래픽카드를 같이 쓰는 동안 잰 값이라 부정확합니다. 재부팅 후 `npm run bench`로 다시 재야 합니다. 비 효과는 같은 화면에서 켜고 끄면 약 3% 느려지고, 드라이버 시점은 약 95~110 fps였습니다.
- **AI 첫 바퀴 사고**: 스파·스즈카·모나코에서 출발 직후 날개를 잃는 차가 6~7대 나옵니다. 팀별 속도 차이가 생기면서 조금 늘었습니다.
- **실기기 미확인**: 휴대폰 화면, 음성 채팅 마이크 버튼, iOS 사파리, ARM 기기(친구 렌더링 실패 건)는 아직 실제 기기에서 확인하지 못했습니다. 렌더링 실패 시 이제 화면에 원인과 그래픽칩 이름이 나오므로, 그 캡처를 받아 고치면 됩니다.
- **모나코 한계**: 헤어핀·카지노 주변 언덕이 맨 포장 둔덕처럼 보입니다(지형 자료에 건물 높이가 섞임). 페어몬트 호텔은 단순한 상자이고, 피트 레인은 트랙과 나란히만 있습니다.
- **기타**: 핸들 화면 배터리 값은 임시 값입니다(ERS 없음). 정밀 팀 도색(UV)은 아직입니다. 구매한 도메인 연결은 정확한 도메인 이름을 받은 뒤 진행합니다.

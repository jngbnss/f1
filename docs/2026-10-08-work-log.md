## 2단계: 물리 기반 (`6b214dd`)

- **F1이 188 km/h에서 막히던 원인**은 속도에 비례하는 구름저항과 차체 감쇠였습니다. 둘 다 고쳤습니다.
- 엔진은 출력(kW) 기반입니다. 힘 = min(접지 한계, 출력 / 속도)이고, 공기저항은 ½ρCdA·v²입니다.
- 타이어는 마찰원 방식입니다. 횡력과 가속·제동력이 μ·하중을 나눠 쓰고, 하중에 다운포스가 포함됩니다.
- **F1 측정 결과**: 최고 339 km/h, 0-200 5.2 s, 200→0 제동 55 m, 300 km/h에서 횡가속 5.9 g
- **잔디·그래블은 바퀴마다 판정**합니다. 잔디는 미끄럽고(μ ×0.32), 그래블은 차를 붙잡아 감속시킵니다.
- **레이싱 라인을 직접 계산**합니다. 넓힌 도로 폭 기준의 최소 곡률(아웃-인-아웃)로 풀고, 느린 코너는 레이트 에이펙스를 적용합니다.
- 목표 속도와 AI 제동이 다운포스를 반영합니다.
- `scripts/handling.ts`: 0-100, 최고속도, 제동 거리, 속도별 횡 g를 재는 도구

- **5등급 × 20대**: 스트리트, 스포츠, GT 레이스, 하이퍼(르망 하이퍼카 포함), 포뮬러(F1 11팀 + F2/F3/FE/인디카 등)
- 차마다 실제 출력, 무게, 최고속도, 구동 방식, 크기를 넣었고, 물리·변속기·엔진 소리를 자동으로 만듭니다.

- **상대 AI는 같은 등급에서 PI가 가장 가까운 차들**이고, 각자의 속도 프로파일로 달립니다.
- **외형**은 실제 크기를 바탕으로 코드로 만듭니다(해치백, 세단, 쿠페, 로드스터, 미드십, GT3, 하이퍼카, LMP). 싱글시터는 F1 차체를 차 크기에 맞춰 조절하고, 인디카는 에어로스크린을 씁니다.
- **솔직한 한계**: 실사 수준의 3D 모델은 아닙니다. 차 형태와 비율, 색으로 구분되는 수준입니다.
  - 무료이면서 라이선스가 확인된 실제 차 모델 100개는 자동으로 구할 수 없었습니다. Sketchfab 다운로드는 계정과 API 키가 필요하고, 모델마다 품질과 용량 차이도 큽니다.
  - `visualFor()`에서 차별로 GLB를 끼울 수 있게 해 두었습니다.
- 테스트: 100대 전부 기본 조작 통과, F1으로 16개 서킷 완주, 서로 다른 등급으로 20대 레이스 3번 모두 전원 완주
